# LegalEase: AI-Powered Legal Document Generator

LegalEase is a lightweight, full-stack application that generates formal legal documents and contracts based on custom user inputs using OpenAI's GPT models. The project consists of a Python FastAPI backend and a modern frontend styled with Tailwind CSS.
